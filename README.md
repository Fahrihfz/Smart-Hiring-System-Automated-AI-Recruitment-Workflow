# Smart-Hiring-System-Automated-AI-Recruitment-Workflow
Smart Hiring System with n8n  is an automated workflow that streamlines candidate screening. By integrating Gmail, Google Gemini AI, Google Sheets, and Google Calendar, it automatically parses CVs, evaluates applicant fit, logs recruitment data, and schedules interviews—eliminating manual initial reviews and speeding up hiring.
